# Results and leaderboards

This directory contains compact, reviewable summaries derived from completed
runs. Raw or large generated artifacts should live outside Git unless they are
small and necessary to substantiate a portfolio result.

## Tracks

- Paper-reproduction results live with their paper under `papers/`.
- Cross-algorithm results are recorded in `leaderboard.csv`.
- Each benchmark family has its own rows and comparisons.

An algorithm is added only after every declared seed has completed under the
same benchmark version. Missing, failed, and excluded runs must be documented.

The leaderboard intentionally starts empty. Placeholder or hand-entered scores
must not be presented as experimental evidence.
